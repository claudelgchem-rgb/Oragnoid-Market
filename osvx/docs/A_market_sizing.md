### 0.1 세 가지 불리한 사실 (먼저 기록)

1. **시장이 작다.** 전 세계 Matrigel/BME 카테고리 전체가 2024년 **97 M USD** 다 [E-318]. 이 안에는 오가노이드가 아닌 용도(invasion assay·xenograft 동시주입·2D 코팅)가 다수 섞여 있으며, Matrigel 언급 논문 중 오가노이드 동시언급은 **28.8%(2025)** 에 불과하다 [E-331]. 오가노이드 전용 매트릭스 시장은 상향식으로 **43 M USD** 다 [E-334].
2. **DECISION_GATE 는 파라미터 조정으로 통과 불가하다.** SAM_2030 기준 150 M USD 는 base TAM_addressable(50.49 M USD)의 **3.0배**다. 전환확률과 증분지출비율을 **1.0(= 2030년까지 전 addressable 시장이 100% 우리 제품으로 전환)** 으로 놓아도 50.49 M USD 로 기준의 **33.7%** 에 그친다 [E-340].
3. **시장보고서를 인용하면 5.35배 과대평가한다.** 오가노이드 시장 보고서 5종 중앙값(1,180 M USD)에 매트릭스 비중을 곱하면 230 M USD 가 나오는데 [E-336], 이는 **모든 용도를 합친 3D 매트릭스 시장 총액(117 M USD)의 1.96배**다. 오가노이드용 매트릭스 지출이 전 용도 매트릭스 지출 총액보다 클 수 없으므로 이 경로는 논리적으로 기각된다.

### 0.2 유리한 사실

1. **물량은 금액보다 빠르게 자란다.** 물량 CAGR 14.20% > 금액 CAGR 11.97% [E-338]. 단가 하락(중국 로컬 21.30 USD/mL [E-125], Corning Synthegel 37.08 USD/mL [E-130])을 반영해도 물량은 10년간 3.8배가 된다. **원가 우위가 있는 대량 생산자에게 유리한 구조**다.
2. **제약 전임상이 2030년에 학술을 추월한다.** 2025년 학술 25.34 : 제약 9.31 (2.7:1) → 2030년 학술 35.25 : 제약 37.65 (0.94:1) → 2035년 39.71 : 66.00 (0.60:1). Agent B 의 nam_ramp 를 램프 함수로 연동한 결과이며, **성장 전액이 제약 세그먼트에서 나온다** [E-078][E-321].
3. **GMP 구간은 비어 있으나 2033년까지 무의미하다.** GMP 세그먼트 TAM 2025 0.09 M USD → 2030 0.50 M USD → 2035 2.51 M USD. Agent B 의 clinical_timing_year 2033 [E-079]과 정합하며, CGT 임상 1,905건 중 오가노이드 이식은 4건 이하(0.21%) [E-328][E-067].

## 1. 정의 (TAM / SAM / SOM / Addressable)

| 개념 | 본 보고서의 정의 | 산식 |
|---|---|---|
| **TAM** | 전 세계 모든 세그먼트·지역에서 **오가노이드 3D 배양에 실제로 소비되는 매트릭스**의 최종사용자 지불액(USD) 및 소비량(L/년). 매트릭스 종류(BME·합성·콜라겐)를 불문한다. 오가노이드가 아닌 BME 용도(invasion assay, xenograft 동시주입, 2D 코팅)는 **제외**한다. | Σ 단위수 × 단위당 mL/년 × ASP |
| **TAM_addressable** | TAM 중 **defined(조성 정의) 매트릭스로 기술적 대체가 가능한** 부분. Agent D 의 효능 격차(2024년까지 모든 합성 매트릭스가 외인성 라미닌 필수 [E-231])와 장기별 입증 편중을 반영. BME 전량이 대체 가능하다고 가정하지 않는다. | TAM × 세그먼트별 대체가능 비율 [E-342] |
| **SAM** | TAM_addressable 중 LG화학이 **실제로 매출로 전환할 수 있는** 부분. **Matrigel 잠식률이 아니라 증분 지출 수용률로 모델링한다** (Agent D 강제 지시 — 리뷰어가 Matrigel 대조군을 요구하므로 전환 후에도 Matrigel 구매가 지속되며, 우리 제품은 기존 지출 위에 얹히는 증분 지출이 된다 [E-239][E-238]). | TAM_add × 누적채택(t) × 증분지출비율 |

### 2.3 채택 결정과 근거

> **경로1 (Bottom-up) 을 주 경로로 채택한다. 경로3 을 검증용으로 병기한다. 경로2 는 기각한다.**

**경로2 기각 사유 4가지 (전부 정량)**

1. **논리적 불가능.** 경로2(230.1 M USD)는 **전 용도 3D 매트릭스 시장 총액(117.2 M USD)의 1.96배**다 [E-335][E-336]. 오가노이드용 매트릭스 지출이 모든 용도의 매트릭스 지출을 초과할 수 없다.
2. **물량 지표 부재 → 본 임무 규정상 부적합.** 조사한 9개 시장보고서 중 물량 단위(L 또는 K Units)를 명시한 것은 QYResearch Matrigel 보고서 **1개뿐**이며 [E-318], 나머지 8개는 전부 금액 단독이다 [E-312][E-313][E-314][E-315][E-316][E-317][E-319][E-337]. 임무 규정 "금액만 있는 시장보고서 인용은 부적합 처리"를 그대로 적용한다.
3. **보고서 상호 비정합.** 동일 카테고리 `3D cell culture market` 2025년 값이 MarketsandMarkets 1.29 B USD [E-316] vs Precedence 2.12 B USD [E-317] 로 **1.64배** 차이난다. 동일 카테고리 `human organoids market` 2025년 값도 GVR 987 M vs MnM 1,352 M 으로 1.37배 차이난다.
4. **정의 불명 → T3 강등.** 6개 보고서 중 **매트릭스 포함 여부를 명시한 것은 Mordor 1개뿐**이다 [E-314]. MarketsandMarkets 는 제외 항목을 아예 기재하지 않는다 [E-316]. Grand View 와 Fortune 은 `Reagents`, `Supplements, Media & Reagents` 라는 상위 분류만 제시하고 매트릭스 하위 분해를 공개하지 않는다 [E-312][E-315]. 전건 T3·신뢰도 하로 처리했다.

**경로1 채택 근거 3가지**

1. **독립 검증 통과.** 학술 세그먼트에서 완전히 독립한 두 방법(랩 수 × 소모량 × 단가 상향식 vs 시장보고서 응용 분할 하향식)이 **1.30배 이내로 수렴**했다 [E-341].
2. **물량과 금액을 동시에 산출한다.** 임무의 이중 축 요구를 충족하는 유일한 경로다.
3. **입력이 전부 1차 측정치다.** PubMed esearch [E-300][E-301][E-305], NIH RePORTER API [E-306][E-307], ClinicalTrials.gov API [E-308], 프로토콜 논문의 실측 부피 [E-309][E-310][E-311], Agent C 의 실측 42개 제품 단가 [E-161].

**경로3 검증용 채택 근거**: QYResearch Matrigel 보고서는 **물량 단위를 명시한 유일한 보고서**이며 [E-318], Agent C 가 독립 확보한 별개 보고서(2024년 88 M USD → 2032년 197 M USD, CAGR 12.2% [E-168])와 **10.2% 이내로 수렴**한다. 두 개의 독립 벤더 보고서가 Matrigel 카테고리에 대해 수렴한다는 사실이 이 수치의 신뢰도를 뒷받침한다.

## 4. NAM 정책 시나리오 연동 — 램프 함수 (스텝 변화 금지)

Agent B 의 `nam_ramp` 3점 앵커(2026/2030/2035)를 **구간별 기하 보간**으로 연속화한다.

```
ramp(t) = ramp(t0) × [ (ramp(t1)/ramp(t0))^(1/(t1−t0)) ]^(t−t0)

base 구간 성장률 (직접 계산):
  2026→2030 : (0.25/0.08)^(1/4) − 1 = 3.125^0.25 − 1 = 0.3296 → 32.96 %/년
  2030→2035 : (0.45/0.25)^(1/5) − 1 = 1.800^0.20 − 1 = 0.1247 → 12.47 %/년
2025 값은 2026→2030 성장률로 역외삽: 0.08 / 1.3296 = 0.0602 → 6.0%
```

## 7. SAM — 증분 지출 수용률 모델 (Agent D 강제 지시 준수)

### 7.1 왜 잠식률이 아니라 증분 지출인가

Agent D 의 구조적 발견 [E-239][E-238][E-237]:

> *"Validating these alternatives typically requires a reference point, and that reference point is **almost always Matrigel-based**."*

전환에 성공해도 고객은 Matrigel 구매를 끊지 못한다(리뷰어가 대조군을 요구). 따라서 우리 제품은 Matrigel 을 **대체**하는 것이 아니라 그 **위에 얹히는 증분 지출**이 된다. 이를 모델에 반영하면:

```
전환 랩의 매트릭스 예산 구성:
  기존 BME 유지분 (대조군용)   = 기존 지출의 0.40
  신규 defined 지출            = 기존 지출의 0.70   ← 우리가 얻는 부분
  랩 총 매트릭스 지출          = 기존의 1.10배 (예산 증액 필요 → 채택 마찰)

incremental_spend_ratio = 0.70  (bear 0.55 / bull 0.85)   가정 A-A20
```
