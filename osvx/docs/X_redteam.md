## 0. 결론 — 이 사업을 죽이는 다섯 문장

1. **제품의 핵심 화학이 성립하지 않는다.** mTG 의 ε-(γ-glutamyl)lysine 가교는 *"단백질이 부분적 또는 완전히 변성된 고온 조건에서만 도입되며, 삼중나선은 천연 상태에서 고도로 정렬되어 있어 비변성 조건에서 글루타민 잔기가 mTG 에 접근 불가능하다"* [E-723]. Agent F 가 확정한 회피설계 스펙(삼중나선 20~80 wt%, 가교 4~25 ℃ / 60~120분)에서 **삼중나선 분획은 원리적으로 가교되지 않는다.** 변성시키면 제품은 젤라틴+mTG 겔이 되고, 그것은 이미 시장에 있는 101Bio Col-Tgel [E-120, C] 이며 Agent F 의 광의 조성물 청구를 소멸시킨 선행기술 그 자체다.
2. **가격 기준선이 잘못 잡혀 있다.** Agent G 의 확정 정가 32.00 USD/mL 은 Matrigel 대비 −28.5% 할인이 아니다. Corning 이 실제로 파는 표준 SKU 354234 는 **302.85 USD / 10 mL = 30.29 USD/mL** [E-715] 이고, Corning 의 최신 defined SKU Synthegel 354791 은 **34.12 USD/mL** [E-716] 이다. 우리 가격은 표준 Matrigel 대비 **+5.6% 프리미엄**이다. 그리고 Corning 은 전사 GAAP 총이익률 36.0% [E-713], Bio-Techne 는 64.8% [E-712] 를 갖고 있어 각각 **19.39 USD/mL / 26.82 USD/mL 까지 인하해도 총이익 손익분기**다 [E-747].
3. **G 의 구제책 (b) 는 산술 오류로 게이트를 통과했다.** GM60 임계물량 191.8 L 은 **ASP 32.00 USD/mL 에서 유도된 값**이다. 옵션(b)의 2028년 물량 믹스는 블렌디드 ASP 18.50 USD/mL 이며, 같은 원가함수에서 임계물량은 **347.3 L** 이다 [E-748]. 옵션(b)의 2028년 물량 258.9 L 에서 실제 GM 은 **47.7%** — **FAIL** 이다. 통과연도는 2028년이 아니라 **2029년**이고, 반증을 반영하면 **2032년 이후**다.
4. **G 의 구제책 (서비스 상쇄) 는 인건비 단가 오류로 성립했다.** 랩당 9,851 USD 는 fully-loaded FTE 90,000 USD 가정에서 나왔다. 제약·바이오 Field Application Scientist 의 중앙값 총보상은 **152,625 USD** [E-741] 이고 fully-loaded 배수는 1.25~1.45× [E-742] 다. 재계산하면 랩당 **18,249 USD**, 5년 분산 시 순단가 3.92 USD/mL < COGS 5.368 → **GM −36.8%** [E-749]. G 가 "5년 분산에서는 성립"이라고 결론낸 조건에서도 성립하지 않는다.
5. **LG화학이 이 사업을 승인할 조직이 아니다.** 생명과학본부 2025년 매출은 9억 5,960만 USD, 영업이익 1억 1,350만 USD 다 [E-733]. SOM_2030 747,000 USD 는 본부 매출의 **0.078%** 다. 그리고 LG화학은 **2025-08-07 이사회에서 연매출 약 1,000억원(70.9 M USD)의 에스테틱 사업을 "항암제 집중"을 이유로 VIG파트너스에 매각했다** [E-735][E-736]. 본 사업의 2030년 매출은 **방금 비핵심으로 판정해 매각한 사업 매출의 1.05%** 다.

### 0.2 사업에 유리한 반대 증거 — 먼저 기록한다 (증거 없는 비관 방지)

레드팀이라도 반대 방향 증거를 은폐하면 실패다. 조사 중 확인된, **이 사업에 유리한** 사실 3건:

1. **mTG 가교 자체는 세포독성이 없다.** mTGase 가교 콜라겐 스캐폴드의 섬유아세포 생체적합성·형태는 천연 콜라겐 대조군 대비 *"영향받지 않았다"* [E-724]. 따라서 H7 은 "독성" 축에서는 무효이며 "천연 삼중나선 가교 불능"·"비분해성 가교" 축에서만 유효하다.
2. **과가교에 의한 광학 저하는 미미하다.** 트랜스글루타미나제 0.06% 에서 젤라틴 겔 투과율은 100% → 99.31% 로 −0.69%p 변화에 그친다 [E-725]. 이미징 저하 가설은 정량적으로 약하다.
3. **Agent E 의 원료비 0.50% 주장은 방향성이 옳다.** 중국 고순도 재조합 콜라겐 실단가 20~22만 CNY/kg = 29.64~32.61 USD/g [E-719] 로 E 의 [E-402] 29.64 USD/g 가정을 독립 확인했다. 삼중나선 titer 오류(§7)를 반영해도 원료비는 0.161 → 0.392 USD/mL 로 GM 을 0.8%p 만 깎는다. **원료비는 이 사업의 킬 팩터가 아니다.**

## 1. 방법 — 정량 임팩트 계산 규약 (R4)

```
반증 Hk 에 대해
  잔존계수 f_k ∈ (0,1]  = Hk 가 참일 때 SOM_2030 에 곱해지는 잔존 비율
  삭감액 = 747,000 × (1 − f_k)  [USD]
  삭감률 = (1 − f_k) × 100      [%]
  참일확률 p_k = 주관 확률(근거 명시)

Bear-case SOM(2030)
  독립 가정 : SOM_bear = 747,000 × Π_k [ 1 − p_k × (1 − f_k) ]
  상관 보정 : 동일 메커니즘 클러스터는 곱하지 않고 최댓값(=가장 강한 삭감)만 반영
```

**Agent E 원가함수 재구성 (모든 GM·임계물량 재계산의 기반)** [E-747]

```
E HANDOFF 3개 값으로 선형 원가함수를 역산한다.
  cogs(100 L) = 23.863 USD/mL,  고정비 비중 @100 L = 0.969,  cogs(500 L) = 5.368 USD/mL

  연간 고정비 F = 23.863 × 0.969 × 100,000 mL = 2,312,325 USD/년
  단위 변동비 v = 23.863 × (1 − 0.969)        = 0.740 USD/mL
  COGS(V) = F / V + v            (V 단위 mL/년)

  검산 : F/500,000 + v = 4.625 + 0.740 = 5.364 USD/mL   (E 공표 5.368, 오차 0.07%)  ✔

GM 60% 임계물량
  V_min(ASP) = F / (0.40 × ASP − v)
  검산 : V_min(32.00) = 2,312,325 / (12.80 − 0.740) = 191,735 mL = 191.7 L
         (E 공표 191.8 L, 오차 0.05%)  ✔
```

> **이 재구성이 §11(H11) 의 결정적 반증을 가능하게 한다.** `V_min` 은 ASP 의 함수이며, Agent G 는 이 사실을 고려하지 않고 191.8 L 을 상수로 사용했다.

### 3.2 이 격차가 LG 가설에 더 불리한 이유 — 3가지 구조적 차이

1. **72% 를 낸 설계는 MMP 절단성 가교를 쓴다** [E-705]. mTG 가 만드는 ε-(γ-glutamyl)lysine 결합은 MMP 기질이 아니다. 오가노이드의 budding·확장은 국소 매트릭스 분해를 요구하는데, 우리 가교는 그 경로를 제공하지 않는다.
2. **72% 를 낸 설계는 인테그린 리간드를 공학적으로 배치했다**(GFOGER 펩타이드). 우리 제품은 천연 콜라겐의 GFOGER 모티프에 의존하며, 그 모티프는 **삼중나선 상태에서만 인테그린 α2β1 에 인식된다** — 그런데 §7 에서 보듯 삼중나선은 mTG 가 가교하지 못한다.
3. **72% 는 전문 랩의 출판된 최고치이지 상용 제품의 평균이 아니다.** Agent D 의 must_win #1 은 "Matrigel 34% 대비 비열등, 즉 절대 ≥34%" 이다 [E-233]. Matrigel 대비 72% 는 절대값 **24.5%** 로 **must_win #1 을 미달한다.**

## 8. H7 — ★ mTG 가교의 기술적 한계: 이 제품의 화학이 성립하지 않는다

### 8.1 결정적 문헌 — 천연 삼중나선은 mTG 로 가교되지 않는다

*Biomacromolecules* (ACS), "Cross-linking of type I collagen with microbial transglutaminase: identification of cross-linking sites" [E-723]:

> *"ε-(γ-glutamyl)lysine cross-links are **only** incorporated at elevated temperatures when the protein is **partially or completely denatured**."*
> *"A maximum number of **5.4 cross-links per collagen monomer** were found for **heat-denatured** collagen."*
> *"Because the triple helix is highly ordered in its native state, this finding might explain why the **glutamine residues are inaccessible for mTG under nondenaturing conditions**."*

### 8.2 이것이 왜 치명적인가 — 제품 정의의 내부 모순

```
Agent F 확정 회피설계 스펙 [F design_around_specs]
  · triple helix       20 ~ 80 wt%
  · 가교 조건          4 ~ 25 ℃ / 60 ~ 120분 (2단 저온가교)
  · 콜라겐 : mTG       ≥ 400 : 1

문헌 사실 [E-723]
  · 4 ~ 25 ℃ 에서 I형 콜라겐 삼중나선은 비변성 상태다 (변성온도 약 37~40 ℃)
  · 비변성 삼중나선의 Gln 잔기는 mTG 에 접근 불가능하다

→ 두 갈래 중 하나만 가능하다.
  (경로 1) 저온 유지 : 삼중나선 20~80 wt% 는 가교되지 않고 물리적 충전재로만 남는다.
           실제 가교되는 것은 단일사슬(변성/단편) 분획뿐 →
           삼중나선 프리미엄 단가 2.50배 [Agent E §1.1] 를 지불하고 기능은 얻지 못한다.
  (경로 2) 승온 변성 : 삼중나선이 소멸한다. 제품은 젤라틴 + mTG 겔이 된다.
           = 101Bio Col-Tgel [E-120, Agent C] 과 동일. 그리고 Col-Tgel 은
             Agent F 가 "광의 조성물 청구 불가" 판정의 근거로 든 선행기술이다
             (Col-Tgel 청구항 1 + PLOS One 2014 [E-164]).
           → 특허 포지션 P1(single:triple 혼합비 20~80 wt% 회랑) 도 동시에 소멸한다.
```

**즉 이 제품은 "삼중나선을 넣으면 가교가 안 되고, 가교가 되게 하면 삼중나선이 사라져 선행기술이 된다."**
