## 2. ★ 침투율 S-curve — 유도 전문 (선형 점유율 가정 없음)

### 2.1 함수형과 파라미터

```
P(t) = L / (1 + exp(−k (t − t0)))                                    [E-819]

  L  = 최종 침투율 (ceiling)
  k  = 기울기 (1/년)
  t0 = 변곡점 (연도)
```

### 2.2 L(ceiling) 유도 — Agent D 의 대조군 요구에서

Agent D 의 구조적 발견 [E-239]: *"대체재 검증에는 기준점이 필요하고, 그 기준점은 거의 항상 Matrigel 이다."*
따라서 전환에 성공해도 고객은 BME 구매를 끊지 못한다. Agent A 는 이를 `기존 지출의 0.40 유지 + 신규 defined 지출 0.70` 으로 모델링했다 [A-A20].

```
L (비GMP 세그먼트) = 증분 defined 지출 ÷ 전환 후 총 매트릭스 지출
                   = 0.70 / (0.40 + 0.70) = 0.6364        (base)
   bear : 0.55 / (0.40 + 0.55) = 0.5789
   bull : 0.85 / (0.40 + 0.85) = 0.6800

L (재생의료 GMP)  = 1.0000
   근거 : GMP 구간은 Matrigel 사용 자체가 불가하므로 [E-240] 대조군 유지 요구가 없다.
          전환 시장이 아니라 신규 채택 시장이다.
```

> **주의 (V-11 반영):** Agent A 는 `0.70` 을 "기존 지출의 0.70" 으로 정의하고 이를 `TAM_addressable` 에 곱했다 — 정의와 적용이 어긋난다. 본 모델은 **0.70 을 곱셈 계수가 아니라 S-curve 의 천장으로 재정의**해 이 불일치를 제거했다. 결과적으로 `TAM_addressable × P(t)` 라는 단일 곱만 남는다.

### 2.3 t0(변곡점) 유도 — Agent D 의 반감기 그대로

```
t0(seg) = 진입연도 2026 + half_life_years(seg)          [E-263]
```

### 2.4 k(기울기) 유도 — 진입 첫해가 D 의 연간 전환확률과 일치하도록

로지스틱을 D 의 위험률 모델에 정박시키는 조건을 세운다.

```
조건 : P(2026) / L = p        (진입 첫해 침투율이 D 의 연간 전환확률 p 와 같다)

  p = L/(1+exp(−k(2026−t0))) ÷ L = 1 / (1 + exp(k·H))          (H = half_life)
  ⇒ 1/p − 1 = exp(k·H)
  ⇒ ★ k = ln(1/p − 1) / H
```
