## 1. 검증 방법

### 1-1. 표본 선정 기준
`docs/R_plan.md` §2 의 P1~P4 우선순위를 그대로 적용했다. 결과 JSONL 의 `sampled` 필드가 `true` 인 118건이 실검증 대상이며, 나머지 320건은 `sampled: false` 로, **URL 호스트·발행주체·source_type 에 근거한 서면 재판정만** 적용했다.

미선정 사유 3가지:
1. **동일 출처 중복** — 예: Google Patents 특허 원문 52건. patents.google.com 이 반복적으로 HTTP 503 을 반환해 대표 1건(US8642339B2)만 완전 검증했고, 나머지는 FreePatentsOnline 검색 5건의 재현 성공으로 간접 담보했다.
2. **파생 계산치** — `source_type:"추정"` 40건은 원자료 검증 대상이 아니다(입력 근거를 대신 검증했다).
3. **동일 URL 재검증 한계효용** — 예: Adv Sci PMC12713094 는 1회 호출로 E-201·E-235·E-236·E-237·E-238·E-240·E-332 7건을 동시 검증했다.

## 6. 가장 심각한 근거 품질 문제 5개

### 문제 1 — 동일 URL에서 두 에이전트가 서로 다른 값을 기록했고, 둘 중 하나가 틀렸다
`E-103`(Agent C, $608.50)과 `E-223`(Agent D, $756.50)은 **완전히 같은 Fisher URL** 을 근거로 한다. R 의 실호출 결과는 **$756.50**. `E-103` 은 격리했다. 그런데 `E-162`("제조사 직판 대비 유통마진 35.9%, 동일 Cat# 5쌍 실측")가 바로 이 $608.50 에서 나온 값이고, Agent G 의 채널별 실현 순단가 `E-663`(직판 32.00 / 대형유통 OEM 23.55 / 번들 22.86 …) 전체가 그 마진율 위에 서 있다. **실제 마진은 69.0%이므로 GTM 채널 경제성 표 전체가 재계산 대상이다.**

### 문제 2 — COGS 모델의 발효원가 기둥이 원문에 없는 숫자였다
`E-424` 는 "2020 $100/kg → 2025 $25~30/kg → 2028 $8~12/kg" 을 bioprocesstools.com 에서 인용했으나, **원문에는 2026년 $20–40/kg 만 있고 나머지 세 시점 수치는 존재하지 않는다.** 이 레코드는 GM 60% 게이트 판정의 원가측 기준선이다. 더 나아가 원가 축 근거의 절반(15/34 T3)이 동일 블로그와 유사 벤더 페이지에서 나왔다.

### 문제 3 — 단일 URL 오타 하나가 규제 결론 7건을 무너뜨렸다
EU 집행위 로드맵 URL 이 `...7878382fbf0f_en`(오기) vs `...7878382fbff6_en`(실제)로 어긋나 `E-030~E-036` 7건이 전부 404 였다. R 이 정정 URL 에서 표지(Brussels, 1.6.2026 / C(2026) 3497 final)는 복구했으나, **`E-031`(ATMP 제외), `E-034`(1,500만 마리/40%), `E-035`(EUR 265억 시장)의 본문 수치는 끝내 1차 원문에서 확인하지 못해 격리**했다. 특히 `E-035` 는 시장보고서 수치를 EU 공문서 안에서 재인용한 것으로, 설령 문서에 있더라도 T1 이 될 수 없다(래핑된 T3).

### 문제 4 — FTO "0건" 결론이 검색 파라미터에 민감하다
`E-553`("청구항에 organoid + transglutaminase 동시 포함 = 0건")은 FTO 판정의 1차 근거다. R 이 **기재 URL 그대로 재실행하면 0건이 재현**된다. 그러나 R 이 DB 선택 플래그를 `eurpat=on` → `eupat=on` 으로 한 글자 바꿔 실행했을 때 **"Matches 1 - 2 out of 2"** 가 반환됐다. 즉 이 "0"은 **검색 파라미터 조합에 따라 흔들리는 값**이며, 부재증명(negative claim)을 단일 무료 검색엔진 한 번으로 확정한 구조 자체가 취약하다. FTO 는 스코어카드상 T1 89.2%로 최고점을 받지만 **실검증 비율은 10.8%로 최저**라는 점이 이 취약성을 가린다.
**→ Agent F 지시**: `E-553·E-554·E-555` 를 (a) USPTO Patent Public Search, (b) EPO Espacenet, (c) WIPO PATENTSCOPE 3개 관청 DB에서 각각 재실행하고, 3곳 모두 0건일 때만 "미점유 청구영역" 판정을 유지하라. 1건이라도 나오면 청구항 전문을 읽고 FTO 등급을 재산정하라.

### 문제 5 — 최상위 결론값이 자기 추정으로 지지되고 있다
`source_type:"추정"` 40건 중 33건이 T1/T2 로 기재돼 있었고, 그 안에 **TAM(`E-334`), 세그먼트 물량(`E-338`), SAM 전환확률 반영(`E-339`), DECISION_GATE 판정(`E-340`), SOM 하향 배수 20.0배(`E-661`), GM60 게이트 도달연도 2042~2057(`E-654`,`E-655`)** 이 전부 들어 있다. 이들은 사업 Go/No-Go 를 직접 결정하는 숫자인데, **독립성 0점 + 이해상충 0점**이다. 게이트 판정을 자기가 만든 숫자로 하고 있으므로, 최소한 각 추정의 **입력 E-ID 가 전부 T1 검증 통과 상태인지**를 별도 표로 명시해야 한다(R4 Show-Your-Math 의 실질적 요구).
