### 1.2 판정 근거 3줄

1. **시장이 게이트의 3%다.** SOM 2030 = **454,332 USD / 판매 19.76 L** 로 DECISION_GATE 15 M USD 의 **3.0%**, SAM 2030 = **5,617,439 USD** 로 게이트 150 M USD 의 **3.7%** 다 [E-820][E-821]. 게이트를 채우려면 2030년 판매물량이 652.3 L 이어야 하는데, 이는 그 해 기술적 대체가능 시장 물량 1,521.7 L 의 **42.9%** 다. 실측 벤치마크는 defined 대체재 7종의 20년 누적 인용 점유율 **1.95%** 이며 [E-152], Corning 자사 defined 제품 Synthegel 의 전기간 PubMed 인용은 **1건**이다 [E-709].
2. **원가가 물량에 갇혔다.** GM 60% 통과에는 ASP 24.93 USD/mL 기준 **판매 209.5 L**(생산 250.5 L)이 필요한데 2030년 base 판매물량은 19.76 L(임계의 **9.4%**), 2035년(84.86 L)에도 40.5%다 [E-824][E-836]. 10년 누적 FCF −19,996,136 USD, Payback 미도달, IRR은 전 기간 FCF가 음수여서 정의되지 않는다 [E-822].
3. **제품의 유일한 고유 자산이 화학적으로 작동하지 않을 수 있다.** mTG 의 ε-(γ-glutamyl)lysine 가교는 단백질이 부분·완전 변성된 조건에서만 도입되며, 천연 삼중나선의 글루타민(Gln) 잔기는 비변성 조건에서 mTG 에 접근 불가능하다 [E-814][E-723]. 저온(4~25 ℃)을 유지하면 삼중나선 프리미엄 단가 **2.50배**를 지불하고 가교 기능을 얻지 못하고, 승온 변성시키면 제품이 101Bio **Col-Tgel**(젤라틴 + 트랜스글루타미나제 2액형, 38.90 USD/mL)과 같아진다 [E-120][E-552].

### 1.3 최대 리스크 3줄

1. **기술 리스크 — H7(mTG × 천연 삼중나선).** 참일 확률 50%, 참이면 SOM 잔존계수 0.448 [E-723]. 다만 **H7 이 거짓이어도 판정은 바뀌지 않는다** — H7 을 완전히 제거한 상태(base)의 SOM 이 이미 게이트의 3.0%이기 때문이다. **No-Go 의 근거는 단일 반증이 아니라 게이트 격차 그 자체다.**
2. **효능 리스크 — 라미닌(laminin-111) 무첨가 설계의 성립 여부.** 2024년까지 **모든** 합성 매트릭스가 외인성 라미닌 보충을 필요로 했다 [E-231]. 라미닌이 필요해지면 COGS 가 +110.96 USD/mL 상승해 [E-412] 공헌이익이 음수가 되고, 어떤 물량으로도 회수가 불가능해진다. 발생확률 40% [D-A07].
3. **조직 리스크 — 사업 규모가 의사결정 기준 미달.** LG화학 생명과학본부 2025년 매출은 959.60 M USD, 영업이익 113.50 M USD 이며 [E-733], SOM 2030 = 0.45 M USD 는 본부 매출의 **0.047%** 다 [E-815]. LG화학은 2025-08-07 이사회에서 연매출 약 70.9 M USD 규모 에스테틱 사업을 "항암제 집중"을 이유로 매각했다 [E-735][E-736].

### 2.2 지연의 합산 방식 — 단순 합산은 오류다

위 지연은 서로 다른 축에 작용하므로 단순 합산(4+7+5+6+3 = 25년)은 성립하지 않는다. 실제로는 축별 최대값이 지배한다.

```
수요 발생 시점 지연 = max(P1 +4, P2(병행제출) 0)        = +4년  → 2030
GMP·이식 매출 시점  = max(P3 +5, P4 +6)                  = +6년  → 2033   [E-079]
ASP 조정            = P5 → GMP 프리미엄 배수 1.75배      [E-077]
```

### 4.5 SAM · SOM — 침투 S-curve 적용

SAM 은 Matrigel 잠식률이 아니라 **증분 지출 수용률**로 모델링한다. 대체재 검증에는 기준점이 필요하고 그 기준점은 거의 항상 Matrigel 이므로 [E-239], 전환에 성공해도 고객은 BME 구매를 끊지 못한다.

```
P(t) = L / (1 + exp(−k (t − t0)))                                     [E-819]

  L  = 최종 침투율 천장 = 증분 defined 지출 ÷ 전환 후 총 매트릭스 지출
     = 0.70 / (0.40 + 0.70) = 0.6364  (base)   / bear 0.5789 / bull 0.6800
     GMP 세그먼트만 L = 1.0000 (Matrigel 사용 불가 → 대조군 유지 요구 없음) [E-240]
  t0 = 진입연도 2026 + half_life_years(세그먼트)                        [E-263]
  k  = ln(1/p − 1) / H       (진입 첫해 침투율이 연간 전환확률 p 와 일치하도록 유도)

  검산(학술) : k = ln(1/0.060 − 1)/11.2 = 2.7516/11.2 = 0.2456
               P(2026)/L = 0.0382/0.6364 = 0.0600 = p  ✔
```

### 7.2 ★ H7 — mTG 는 천연 삼중나선 콜라겐을 가교하지 못한다

이것이 본 검증에서 확인된 **가장 강한 단일 반증**이며, 제품정의 자체를 겨눈다.

**[1] 문헌 문언은 확정적이다.** Biomacromolecules 11(3):698-705 (PMID 20131754) 원문 [E-814][E-723]:

> *"ε-(γ-glutamyl)lysine cross-links are only incorporated at elevated temperatures when the protein is partially or completely denatured."*
> *"the triple helix is highly ordered in its native state ... the glutamine residues are inaccessible for mTG under nondenaturing conditions."*

열변성 콜라겐에서 최대 5.4 crosslink/monomer 가 확인되며, 비변성 조건에서는 도입되지 않는다 [E-814]. 이 문헌은 레드팀 기능이 확보한 뒤 통합 기능이 PubMed 경유로 **독립 재확인**했다.

**[2] IP 회피설계 스펙과 직접 모순한다.**

| 항목 | 값 | 함의 |
|---|---|---|
| 회피설계 스펙 P1 | 삼중나선 콜라겐 **20~80 wt%** + single chain 80~20 wt%, 총 콜라겐 5~20 mg/mL | [E-569] |
| 회피설계 스펙 P2 | 가교 조건 **4~25 ℃ / 60~120분** 1차 가교 후 37 ℃ 2차 가교 | [E-569] |
| I형 콜라겐 변성온도 | 약 37~40 ℃ | 4~25 ℃ 는 **비변성 구간** |
| 결과 | 스펙대로 만들면 삼중나선 분획 20~80 wt% 는 가교되지 않는다 | — |

**[3] 두 갈래 모두 사업 논거를 파괴한다.**

| 경로 | 결과 | 정량 |
|---|---|---|
| 경로 1 — 저온 유지 | 삼중나선이 물리적 충전재에 그친다 | 삼중나선 프리미엄 단가 **2.50배**(고순도 20만 CNY/kg 대 화장품급 8만 CNY/kg [E-402][E-403])를 지불하고 기능을 얻지 못한다 |
| 경로 2 — 승온 변성 | 제품이 젤라틴 + mTG 겔 = 101Bio Col-Tgel 과 같아진다 [E-120] | Col-Tgel 은 광의 조성물 청구 불가 판정의 근거인 선행기술 그 자체다 [E-524][E-552]. 특허 포지션 P1(혼합비 20~80 wt% 회랑)도 동시 소멸 |

**[4] 그리고 이 자산이 이 사업의 유일한 정당화 근거였다.** LG화학 보유 매트릭스 특허 0건, mTG 관련 US/EP/PCT 0건이며 IP 는 해자가 아니다 [E-555]. mTG 를 카탈로그(Zedira Andracon T300, 260,077 USD/g 환산)로 구매하면 GM 이 48.5%p 붕괴한다 [E-407]. 즉 "왜 LG화학이어야 하는가"에 답하는 자산은 **GMP mTG 내재화 하나뿐**이며, H7 은 그 하나를 무효화한다.

**[5] ★ 그러나 H7 이 거짓이어도 판정은 바뀌지 않는다.**

```
본 모델에서 H7 을 완전히 제거한 상태(= base 시나리오, LG 점유율 12% 유지)의
  NPV        = −14,069,419 USD
  SOM_2030   = 454,332 USD = DECISION_GATE 15 M USD 의 3.0%

⇒ H7 은 No-Go 의 원인이 아니라 재정의 논의를 봉쇄하는 요인이다.
  "제품을 다시 설계하면 되지 않느냐"는 반론에
  "다시 설계하면 우리일 이유가 없다"고 답하게 만든다.
  No-Go 의 근거는 단일 반증이 아니라 게이트 격차 자체다.
```

**[6] 처분.** H7 에 대한 처분은 명확하다 — **KC-1 을 90일 안에 집행한다**(§13 액션 A1). GGEL ≥ 4.0/monomer 이고 삼중나선 CD 스펙트럼(222 nm)이 유지되면 레드팀은 H7 을 철회하기로 사전 선언했다. 결과가 미달이면 현 제품정의는 재설계가 아니라 **폐기** 대상이다.

| 게이트 | 최선 관측치 (전 기간·전 시나리오) | 판정 |

> **게이트 5개 중 4개 FAIL. 유일한 PASS 는 FTO 이며, 그것조차 회피규격을 자사 저강성 SKU 설계와 국내 파트너십 제안이 위반한 상태다** [E-837]. 본 모델은 해당 SKU 매출을 제거하지 않았으므로 **SOM 은 이 항목에 대해 낙관 편향**이다.
